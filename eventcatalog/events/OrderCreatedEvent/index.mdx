## Overview

The `OrderCreatedEvent` is a **domain event** raised within the Ordering Module when a new `Order` aggregate is created.

> **Note:** The handler for this event (`OrderCreatedEventHandler`) is currently commented out / placeholder. It can be extended to trigger notifications, analytics, or further integration events.
