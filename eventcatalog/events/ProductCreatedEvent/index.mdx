## Overview

The `ProductCreatedEvent` is a **domain event** raised within the Catalog Module when a new product is created via the `Product.Create()` factory method.

This event is handled in-process by the `ProductCreatedEventHandler`, which currently logs the event. It can be extended to trigger additional side effects (e.g., indexing, notifications).

### Trigger

```csharp
// In Product.Create()
product.RaiseDomainEvent(new ProductCreatedEvent { Product = product });
```

### Handler

- **ProductCreatedEventHandler** — Logs the event occurrence.

### Source Files

- `Catalog.Domain/Entities/Product.cs` — Raises the event
- `Catalog.Domain/Events/ProductCreatedEvent.cs` — Event definition
- `Catalog.Application/Features/Events/ProductCreatedEventHandler.cs` — Handler
